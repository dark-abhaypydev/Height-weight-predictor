# 📏 Height & Weight Predictor using Linear Regression

A simple Machine Learning project that predicts **Height** and **Weight** of children based on their **Age** using **Simple Linear Regression**.

## 📌 Features
- Predict Height (in cm) from Age
- Predict Weight (in kg) from Age
- Model trained on real children's data (Age 8-18 years)
- Interactive Streamlit web app
- Visualization of regression lines

## 🛠️ Tech Stack
- Python
- Scikit-learn (Linear Regression)
- Pandas & NumPy
- Streamlit
- Matplotlib

## 📊 Dataset
- Kids198 Dataset
- 198 children
- Age range: 8 to 18 years

## 🚀 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
